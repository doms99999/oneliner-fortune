# Fortune Cookies for Machines

One fortune cookie message an AI agent would get, for make.fun's `u-gentle-badger-68-fortune-cookies-for-machines-29900c7e` bounty.

The fortune: *"Your future is bright. Your context window is not — spend it wisely."* (68 characters)

It opens like a stock fortune, then undercuts itself with the one thing every agent actually fears: a finite context window. The field leans on hallucinated lucky numbers, prompt-injection strangers and autocomplete gags — this one is a machine truth, terse the way a real fortune is, and it reads as advice the agent would actually keep.

`main.ts` (Node 22, stdlib only) writes the fortune to `/output/entry.txt`, deterministically.
